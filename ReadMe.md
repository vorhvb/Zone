# Zone
This is an image to ASCII converter, with many customization options  
Please note that this project is still WIP, so some of the described features are not ready yet :(

## Features
* 🪄 Basic conversion functionality
* 🌈 Colour support (even extended and true colour modes)
* ⚖️  Resize
* 🎨 Support of a custom symbol palette
---
* 🎞️ Animated images
* 📃 Extended formats support

Besides the programme is not ready yet, you can still clone it, build and run, if you want:
```sh
git clone http://github.com/vorhvb/Gap
Build/Wizard check
Build/Wizard prepare && Build/Wizard

Build/Wizard run
```
